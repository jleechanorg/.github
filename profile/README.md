## WorldAI

WorldAI is a story-first RPG with an AI game master. Pick an action or type what you want to do. There are dice, combat, and character progression underneath, but you don’t need to learn the rules to start playing. The game tracks characters, inventory, and the choices you’ve made so the next scene can build on what actually happened.

Use **Act** to move the story forward, **Think** to plan without advancing it, and **God Mode** when you want to change something about your character or world. You can share a campaign as a link so someone else can start their own run.

## Featured open-source projects

### [jleechan-skills](https://github.com/jleechanorg/jleechan-skills)

Reusable workflows for coding agents. Use them to pressure-test a plan, reproduce a bug before fixing it, and make sure a PR’s evidence matches what it claims. Start with the [PR Workflow Manager](https://github.com/jleechanorg/jleechan-skills/blob/main/.claude/skills/pr-workflow-manager/SKILL.md) for the review and evidence loop.

### [ez-gh-actions](https://github.com/jleechanorg/ez-gh-actions)

Self-hosted GitHub Actions runners in a single Rust binary. Each job gets a fresh runner with CPU, memory, and process limits. Runners clean up after the job, and the service stops accepting new work when disk space is too low.

### [Disk Magician](https://github.com/jleechanorg/disk_magician)

Find what’s using space on macOS and Linux, then compare snapshots to see what grew. Disk Magician identifies stale caches and orphaned Git worktrees and lets you preview cleanup before deleting anything.
